# EASYPHOTO

EASYPHOTO is a local web app for creating:
- passport photos
- passport cards with name/date
- sradhanjali / memorial cards
- print layouts for 4, 6, and 10 copies
- AI-assisted editing suggestions
- webcam capture support

## Features
- Passport photo preview and download
- Name + date overlay support
- Memorial card builder
- Camera capture
- AI assistant panel
- Print layout options
- Feature toggles through `app-config.json`

## Run locally

### Windows
```bash
cd path\to\EASYPHOTO
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Then open:
```text
http://localhost:5000
```

### Mac/Linux
```bash
cd path/to/EASYPHOTO
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Then open:
```text
http://localhost:5000
```
